About Budgeting App

The MyBudgetTrackr is a personal finance management tool developed as part of the final project for Harvard's CS50: Introduction to Computer Science. The goal of this app is to help users manage their finances by tracking income, expenses, and setting savings goals, all in one place.

As a CS50 final project, this app demonstrates the application of various programming and web development skills including backend development with Flask, front-end design using HTML and CSS, and integration with a SQLite database for data storage. The project also emphasizes user authentication, secure password handling, and dynamic data rendering in a web environment.

The app is designed with a user-friendly interface, where users can easily input their income and expenses, view reports, set savings goals, and track their financial progress over time. This project was built to showcase the development skills acquired throughout the CS50 course, while addressing a real-world need for effective personal financial management.

Key Features:

  • Track income and expenses
  • Set and monitor savings goals
  • Generate financial reports in PDF format
  • View spending breakdown by category

This project has been developed using Python, Flask, SQLite, and HTML/CSS. It provides a simple, intuitive way for users to take control of their financial situation and work towards their goals.
